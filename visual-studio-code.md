# Visual Studio Code

Visual Studio Code is not a Integrated Development Environment (IDE) like IntelliJ or Eclipse, but a Text Editor like Atom or Sublime Text.

## Shortcuts
1. `ctrl` + `shift` + `E` : open the explorer
2. `ctrl` + `shift` + `F` : open the finder / search
3. `ctrl` + `shift` + `G` : open the git options
4. `ctrl` + `shift` + `X` : open the extensions 
4. `ctrl` + `B` : toggle side menu
5. `ctrl` + `shift` + `P` : command pallet (search for any command available in VS Code)
6. `ctrl` + `F` : find in current file
7. `ctrl` + `tab` : toggle b/w mutlilpe open files or `ctrl` + `shift` + `tab` to go other way
8. `ctrl` + `P` : search files by name and switch to them
9. `ctrl` + `W` : close the current file
10. `ctrl` + (`->` / `<-`) : move word by word

**Zen Mode:** remove all the distractions from the IDE
**Mini-map**: small previes of the current code on side

> You can use Emmet for HTML / CSS code.
