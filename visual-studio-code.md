# Visual Studio Code


## Shortcuts
1. `ctrl` + `shift` + `E` : toggle the explorer
2. `ctrl` + `shift` + `F` : open the finder / search
3. `ctrl` + `shift` + `G` : open the git options
4. `ctrl` + `B` : toggle side menu
5. `ctrl` + `shift` + `P` : command pallet (search for any command available in VS Code)

Zen Mode: remove all the distractions from the IDE
Mini-map: small previes of the current code on side
